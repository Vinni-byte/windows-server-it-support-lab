# Windows Server IT Support Lab

A home lab built to gain hands-on experience with Windows Server,
Active Directory, DNS, networking and common IT support tasks.

## Lab Environment

- Oracle VirtualBox
- Windows Server 2025
- Windows 11 client
- Active Directory Domain Services
- DNS
